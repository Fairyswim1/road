# 수식로드 — AR 수학 탐험

아이폰 Safari / 안드로이드 Chrome에서 실제 물건을 인식해 수학문제를 풀고, 카드를 모은 뒤 관리자 태블릿에서 100을 만드는 웹 게임입니다. HTTPS와 인터넷 연결이 필요합니다. 기존 단일 물건 실험은 `/ar-lab`이고, 본 게임은 `/`에서 새 수업을 만듭니다.

## 수업 진행

1. 모둠 수·이름·수색 시간·풀이 시간·준비할 카드 수·관리자 PIN을 정합니다. 기본 5모둠입니다.
2. **관리자 링크 보관**을 눌러 안전하게 보관합니다. 다른 패드에서도 이 링크로 같은 수업을 엽니다. 학생에게는 전달하지 않습니다.
3. **AR 카드 배치**에서 서로 다른 책 표지·포스터·상자 앞면을 사진으로 등록합니다. 인쇄한 QR은 필요 없습니다. 물건당 수학문제, 정답, 보상 카드를 교사가 직접 입력합니다. 문제는 글·그림·글과 그림 모두 가능하며 JPG·PNG·WebP 그림을 첨부할 수 있습니다. 학생은 그림을 눌러 확대할 수 있습니다. 그림은 최대 2,400픽셀로 정리해 저장하고, 정답은 그림과 별도로 입력합니다. 수색 시작 전 기존 문제의 그림을 교체하거나 삭제할 수 있습니다.
4. 정답은 한 줄에 하나씩 최대 10개 허용합니다. 공백·영문 대소문자·전각 문자는 정규화하지만 수식을 대신 계산하지 않습니다. `1/2`와 `0.5`를 모두 허용하려면 두 줄로 입력합니다. 문제는 최대 2,000자입니다.
5. 물건은 최대 20개, 물건당 카드 1~30장을 연결할 수 있습니다. 인식 데이터 총 용량은 14MB 이하입니다. 배치한 카드만 사용하며, 한 문제를 푼 모둠은 그 물건의 남은 카드를 한 장씩 획득할 수 있습니다. 수색 시작 전에는 문제와 카드 구성을 수정할 수 있습니다.
6. **배치 완료 · 탐색 데이터 저장** 후 관리자 화면으로 돌아가 각 모둠의 **카드·참여 QR**에서 모둠 참여 링크를 전달하고 **수색 시작**을 누릅니다. 참여 QR은 접속용이며 숨길 카드 마커가 아닙니다.
7. 학생은 **AR 탐색 시작 → 물건 인식 → 문제에 답 입력 → 카드 공개 → 획득** 순서로 진행합니다. 틀리면 다시 답합니다. 정답은 서버가 판정하며 정답 이전 카드 조회와 획득을 차단합니다. 문제 해결은 모둠별로 저장됩니다.
8. 먼저 서버에서 확정한 모둠만 카드를 획득합니다. 다른 모둠이 가져간 카드는 표시하지 않고 소유 모둠도 알리지 않습니다. 학생에게는 숨긴 사진·장소·카드 목록과 다른 모둠 정보가 제공되지 않습니다.
9. 모둠이 복귀하면 **복귀 처리**, 전체가 끝나면 **전체 수색 종료**. 시간 종료나 배치된 카드 소진 시에도 수색이 끝납니다.
10. 관리자 패드에서 모둠의 **수식판 열기**. 보관함 카드와 놓을 칸을 차례로 탭합니다. 변경은 자동 저장됩니다.
11. PIN을 입력해 관리자 화면으로 돌아오면 해당 모둠 시간이 정지됩니다. 다음 모둠을 열어도 이전 모둠 시간은 정지됩니다. 새로고침·화면 닫기는 시간을 자동으로 정지시키지 않습니다.
12. **최종 제출** 후 수정은 막힙니다. 완성하지 못한 모둠도 **미완성으로 제출**할 수 있습니다. 모든 모둠이 제출하면 수업이 완료됩니다.

사진 기반 AR은 사진 속 평면을 인식합니다. 공간 좌표에 고정되는 AR이나 임의의 3D 물체 인식은 아닙니다. 같은 표지의 복사본도 인식하므로 장소 인증 수단은 아닙니다. 무늬가 다양하고 반사가 적은 서로 다른 물건을 선택하고, 실제 수업 장소의 조명·거리와 아이폰에서 시험하세요. 카메라 영상은 서버로 전송하지 않습니다. 교사가 등록한 기준 사진과 인식 데이터만 저장합니다.

## 다른 학급에서 재사용

기존 수업 관리자 링크에서 **다른 학급용으로 복제**를 누르고 새 수업 이름, 모둠 수·이름, 관리자 PIN을 입력합니다. 같은 PIN을 다시 사용해도 됩니다. 준비 중·진행 중·완료된 수업 모두 복제할 수 있습니다.

사진·문제 그림·문제·정답·카드 값과 방향·배치·수색 및 풀이 시간·숫자 카드 사용 규칙은 복사합니다. 카드 획득, 문제 해결, 수식판, 사용 시간, 제출 결과와 활동 기록은 새로 시작합니다. 사진 인식 준비가 완료된 원본은 재분석 없이 시작할 수 있습니다. 준비가 끝나지 않은 원본은 새 수업에서도 배치를 마무리하세요.

새 관리자 링크와 모둠 참여 링크가 발급됩니다. 새 링크를 보관하고 학생에게 새 모둠 링크를 전달하세요. 기존 학급은 기존 링크로 계속 확인할 수 있고 새 학급에서 문제를 수정해도 이전 학급에는 반영되지 않습니다. 서버는 불변 이미지·인식 파일을 재사용하며, 수정 시 새로운 파일을 저장합니다.

## 각색한 규칙

- 6×6판, 출발·도착 칸에도 카드 배치. 왼쪽 위에서 오른쪽 아래까지 단일 경로로 연결합니다.
- 카드 회전 금지. 숫자 카드는 붙여서 여러 자리 수로 사용 가능합니다.
- 곱셈·나눗셈 우선, 동순위는 왼쪽부터. 괄호와 단항 음수는 없습니다. 정확한 유리수 연산으로 100을 판정합니다.
- 수색 1회 + 모둠별 풀이. 코인·버리기·탈락 규칙은 사용하지 않습니다.
- 숫자 카드 전부 사용 여부는 관리자가 선택합니다.
- 100 달성팀은 사용 카드 수가 많은 순서, 미달성팀은 100과의 차이가 작은 순서입니다. 동점은 공동 순위입니다.
- 원작의 완전한 카드 목록이 공개되지 않아 수업용 분포를 사용합니다. 무작위 선점 결과마다 100의 해가 존재함을 보장하지 않습니다.

## 저장·권한

Cloudflare D1에 수업 상태가 영구 저장됩니다. 모둠마다 별도 비밀 참여 토큰을 사용하고 관리자에게만 전체 카드·참여 토큰을 제공합니다. 학생 응답에서는 미획득 카드와 다른 팀 정보 및 정답·문제 해결 현황·카드 비밀 코드를 제외합니다. 발견한 문제의 내용과, 정답을 맞힌 뒤 획득할 카드 정보만 별도 API로 제공합니다.

동시 획득은 D1의 revision 조건부 UPDATE로 직렬화합니다. 충돌 시 최신 상태를 다시 검사하므로 동일 카드를 중복 확정하지 않습니다. 판에는 별도의 boardVersion을 적용해 다른 화면의 저장을 덮어쓰지 않습니다. 네트워크 실패를 획득 성공으로 표시하지 않습니다.

관리자 PIN은 패드를 잠시 학생에게 건네는 화면 복귀 제어입니다. 관리자 링크 자체를 가진 사람의 관리 권한을 취소하는 보안 장치는 아닙니다. 관리자 링크를 비밀로 보관하세요. 학생 참여 링크를 다른 모둠에 공유하면 해당 모둠으로 접속할 수 있으므로 모둠별로 전달합니다.

이 사이트는 사용자 승인에 따라 공개되어 GPT 로그인 없이 접속합니다. 수업별로는 수업 정보는 유효한 관리자/모둠 링크를 가진 요청에만 응답합니다. 학생의 이름·위치·카메라 영상을 수집하지 않으며 영상 인식은 브라우저 안에서 수행합니다. 이전 QR 방식 수업은 기존 링크로 계속 사용할 수 있습니다.

## 개발·검증

- `node scripts/run-framework.mjs dev`
- `node node_modules/drizzle-kit/bin.cjs generate`
- `node scripts/run-framework.mjs build`
- `node node_modules/typescript/bin/tsc --noEmit`
- `node --experimental-strip-types scripts/test-game.mjs`
- 로컬 D1 마이그레이션 후 `node scripts/test-api.mjs`
- 로컬 개발 서버에서 `node scripts/test-ar-game.mjs` (문제·정답·모둠별 권한·동시 획득)

통합 테스트는 로컬 테스트 수업을 생성하며 `.sites-runtime/test-session.json`에 테스트 접속 정보만 저장합니다. 이 디렉터리는 Git·배포에서 제외됩니다. 배포판에는 테스트 수업이 들어가지 않습니다.
