# 수식로드 — 야외 수학 수업

아이폰 Safari / 안드로이드 Chrome에서 QR 카드를 수집하고 관리자 태블릿에서 수식판을 완성하는 웹 앱입니다. HTTPS와 인터넷 연결이 필요합니다. 실제 iPhone/iPad 카메라 촬영 검증은 배포 후 현장 기기에서 해야 합니다.

## 수업 진행

1. 수업을 만들고 모둠 수·이름·수색 시간·풀이 시간·카드 수·관리자 PIN을 정합니다. 기본 5모둠, 150장입니다.
2. 생성 직후 **관리자 링크 보관**을 눌러 안전하게 보관합니다. 다른 패드에서도 이 링크로 같은 수업에 접속합니다. 관리자 링크는 학생에게 전달하지 않습니다.
3. **숨길 카드 · 인쇄**에서 마커를 인쇄해 배치합니다. 이 버전은 QR 인식과 카드 획득 연출이며 공간 고정 3D AR은 아닙니다.
4. **카드·참여 QR**에서 각 모둠에 해당 참여 링크를 전달합니다. 같은 모둠은 여러 휴대폰으로 공동 수집할 수 있습니다.
5. **수색 시작** 후 스캔합니다. QR 인식이 어려우면 마커 아래 12자리 코드를 입력합니다. 먼저 서버에서 확정된 모둠만 획득합니다.
6. 모둠이 복귀하면 **복귀 처리**, 전체가 끝나면 **전체 수색 종료**. 제한 시간 종료나 전체 카드 소진 시에도 수색은 종료됩니다.
7. 관리자 패드에서 **수식판 열기**. 보관함 카드와 놓을 칸을 차례로 탭합니다. 놓인 카드를 이동하거나 보관함으로 돌릴 수 있습니다.
8. PIN을 입력해 관리자 화면으로 돌아오면 해당 모둠 시간이 정지됩니다. 다음 모둠을 열면 이전 모둠 시간도 정지됩니다. 새로고침·화면 닫기는 시간을 자동으로 정지시키지 않습니다.
9. 최종 제출 후 수정은 막히며 결과가 저장됩니다. 학생 기기에서는 자기 모둠 카드만 표시됩니다.

## 각색한 규칙

- 6×6판, 출발·도착 칸에도 카드 배치. 왼쪽 위에서 오른쪽 아래까지 단일 경로로 연결합니다.
- 카드 회전 금지. 숫자 카드는 붙여서 여러 자리 수로 사용 가능합니다.
- 곱셈·나눗셈 우선, 동순위는 왼쪽부터. 괄호와 단항 음수는 없습니다. 정확한 유리수 연산으로 100을 판정합니다.
- 수색 1회 + 모둠별 풀이. 코인·버리기·탈락 규칙은 사용하지 않습니다.
- 숫자 카드 전부 사용 여부는 관리자가 선택합니다.
- 100 달성팀은 사용 카드 수가 많은 순서, 미달성팀은 100과의 차이가 작은 순서입니다. 동점은 공동 순위입니다.
- 원작의 완전한 카드 목록이 공개되지 않아 수업용 분포를 사용합니다. 무작위 선점 결과마다 100의 해가 존재함을 보장하지 않습니다.

## 저장·권한

Cloudflare D1에 수업 상태가 영구 저장됩니다. 모둠마다 별도 비밀 참여 토큰을 사용하고 관리자에게만 전체 카드·참여 토큰을 제공합니다. 학생 응답에서는 미획득 카드와 다른 팀 정보 및 마커 비밀 코드를 제외합니다.

동시 획득은 D1의 revision 조건부 UPDATE로 직렬화합니다. 충돌 시 최신 상태를 다시 검사하므로 동일 카드를 중복 확정하지 않습니다. 판에는 별도의 boardVersion을 적용해 다른 화면의 저장을 덮어쓰지 않습니다. 네트워크 실패를 획득 성공으로 표시하지 않습니다.

관리자 PIN은 패드를 잠시 학생에게 건네는 화면 복귀 제어입니다. 관리자 링크 자체를 가진 사람의 관리 권한을 취소하는 보안 장치는 아닙니다. 관리자 링크를 비밀로 보관하세요. 학생 참여 링크를 다른 모둠에 공유하면 해당 모둠으로 접속할 수 있으므로 모둠별로 전달합니다.

새 Sites 배포는 기본적으로 소유자만 접근 가능합니다. 학생이 계정 없이 접속하려면 소유자가 사이트 공개를 승인해야 합니다. 공개 후에도 수업 정보는 유효한 관리자/모둠 링크를 가진 요청에만 응답합니다. 학생의 이름·위치·카메라 영상을 수집하지 않으며 QR 영상 처리는 브라우저 안에서 수행합니다.

## 개발·검증

- `node scripts/run-framework.mjs dev`
- `node node_modules/drizzle-kit/bin.cjs generate`
- `node scripts/run-framework.mjs build`
- `node node_modules/typescript/bin/tsc --noEmit`
- `node --experimental-strip-types scripts/test-game.mjs`
- 로컬 D1 마이그레이션 후 `node scripts/test-api.mjs`

통합 테스트는 로컬 테스트 수업을 생성하며 `.sites-runtime/test-session.json`에 테스트 접속 정보만 저장합니다. 이 디렉터리는 Git·배포에서 제외됩니다. 배포판에는 테스트 수업이 들어가지 않습니다.
